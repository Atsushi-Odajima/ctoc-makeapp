対象: UI と操作体験のみ。ブランド名・投稿データ・認証・API・URL・いいね/保存/投稿の処理は変更していない。

────────────────────────────────────────
1. 改修前に画一的に見えた原因（調査結果）
────────────────────────────────────────
文字組み
  ・本文・名前・ボタン・ナビがほぼ同じ BIZ UDPゴシック 12〜14px。名前14px太字、日時10px、反応11px、
    返信抜粋11px と「小さい文字の太さ違い」だけで階層を作っていたため、見出し/投稿者/本文/日時が一瞬で
    見分けられなかった。
  ・飾りの英字（「TODAY / 10.09 FRI」「MESSAGES」「NOTICE」「YOUR CIRCLES」「NOTE / 10.09」「STEP 1 / 3」
    「PREVIEW」）と大きなキャッチコピー（「話のつづき。」「好きなことから、話そう。」）が画面ごとに入り、
    実際の機能や投稿より目立っていた。
情報の優先順位
  ・ホームの最上部が「今日は、どんな日？」の薄紫カード＋3分割の塗りタブで、スマホでは最初の写真が
    画面の約40%の位置からしか始まらなかった。
  ・プロフィールは薄紫の大きなカード（装飾の大三角形入り）と、KPI風の大きな数字3つで、投稿一覧が
    画面の下半分以降に押し出されていた。
  ・さがす画面は検索欄だけで写真が1枚もなかった。
余白
  ・18px のガターを写真にも適用し、写真が画面端まで届かない。9/10/11/14/17/19/26px など場当たり的な
    値が混在。
投稿レイアウト
  ・写真に 12/3px の角丸、写真の上に全体表示ボタン・左右矢印を常時重ね、枚数「1 / 3」を写真の下に別行で
    表示。反応ボタンは塗りの薄紫ピル、返信抜粋は紫の左線＋薄紫の箱。どの要素も「箱」に入っていた。
ナビゲーション
  ・スマホは濃色の浮遊ナビ（角丸22px・影付き）＋中央の大きな珊瑚色ボタンで、写真の下端を覆っていた。
  ・PCは上部ナビ＋右側に中身の薄いサイドバー（参加している集まり）で、フィード列が左に寄っていた。

────────────────────────────────────────
2. デザインの狙いと構造の変更
────────────────────────────────────────
・投稿は「投稿者 → 写真 → 反応 → 本文」の順。写真はスマホで画面端まで（角丸0）、PCのフィード列（600px）
  では角丸4px。投稿どうしは余白と1本の細線で区切り、カードの箱をやめた。
・写真の枠は1枚目の比率を 4:5〜1.91:1 に収めて事前に確保（読込中に跳ねない）。枠に収まらない写真には
  「全体」の印を出し、タップで元の比率の全体表示（キーボードの←→・Escにも対応）。複数枚は横スワイプ
  （scroll-snap）＋右上の枚数＋下のドット。PCではホバー/フォーカス時のみ矢印。
・本文はフィードで3行まで、「続きを読む」で全文。コメントは「コメントn件をすべて見る」＋最新1件。
・反応: いいね / 気持ちわかる（「わかる」ラベル付き）/ コメント / 保存。反応済みはアクセント色＋塗り
  （保存は塗り）＋aria-pressed で、色だけに頼らない。押した瞬間に180msの小さな拡大。
・ナビ: スマホ下部は5項目（ホーム・さがす・投稿・集まり・自分）にラベル付き。投稿はアクセント色の
  線アイコンで、写真を覆う浮遊ボタンはやめた。DMとお知らせは上部。DMの会話中は下部ナビを隠し、
  入力欄が画面下端を使う。入力中（キーボード表示中）も下部ナビを隠す。セーフエリア対応。
・PC: 上部の1本のバー（ホーム・さがす・集まり・DM・自分＋投稿ボタン＋お知らせ）。フィードは600px中央、
  プロフィール・さがす・保存は960pxまで広げたグリッド。右サイドバーは削除（3カラムにしない）。
  投稿詳細は「写真｜投稿者・反応・本文・コメント・入力」の2ペイン。
・さがす: 検索欄（虫めがね・消去ボタン付き）＋公開写真の3列グリッド（正方形・中央トリミングで統一、
  詳細で元の写真）。検索結果は 人 / 集まり / 投稿グリッド。プロフィールの趣味から検索に飛べる。
・プロフィール: アバター（円）・名前・@ユーザー名・数字1行（投稿/フォロワー/フォロー）→ 自己紹介 →
  3項目（小さな ▲○◆ を行頭記号に残した定義リスト）→ 操作ボタン → タブ（投稿/日記/集まり/下書き）→
  3列グリッド。スマホで投稿一覧が1画面目に入る。
・投稿作成: プレビュー（4:5で全体表示）＋サムネイル列（選択・並べ替え・追加）＋選択中の写真の状態/
  代替テキスト → 本文 → 投稿先 → 公開範囲。PCは左プレビュー・右入力。状態は アップロード中（進捗）/
  処理中 / 準備できました / 失敗（再試行ボタン。この画面で選んだファイルは再アップロードできる）。
・DM: 自分の吹き出しはインク色、相手は白＋細線。送信中/失敗（再送）/送信済み/既読を文字で表示。
・ダイアログ: スマホは下からのシート（つまみ付き）、768px以上は中央。最初の操作にフォーカス、Tab閉じ込め、
  Esc/背景/閉じるで閉じ、開いたボタンにフォーカスを戻す。背面は inert ＋スクロール固定。
・状態の統一: 読み込み中は本物と同じ形のスケルトン、空状態はアイコン＋一言＋次の行動、エラーは
  警告アイコン＋文言＋「再試行」、通知はアイコン付き（色だけにしない）。
・飾りの英字・キャッチコピーを削除し、画面名は日本語の見出しに統一（ホーム・集まり・DM・お知らせ・
  設定 等）。フィードの日付見出しは「今日」「昨日」「10月7日（火）」。

3. フォント
────────────────────────────────────────
・Zen Kaku Gothic New（400 / 500 / 700）: 日本語の本文・ボタン・ナビ・見出しすべて。
    配布元: Google Fonts（github.com/google/fonts ofl/zenkakugothicnew）。著作権 The Zen Kaku Gothic Project Authors。
    ライセンス: SIL Open Font License 1.1（public/fonts/ZenKakuGothicNew-OFL.txt）。
・Barlow Condensed（500 / 600）: 英字ブランド名「DayNet」、@ユーザー名、数（フォロワー数・枚数・未読数・
  ステップ番号）など短い英数字のみ。日本語・長文には使わない。
    配布元: Google Fonts（ofl/barlowcondensed）。著作権 The Barlow Project Authors。
    ライセンス: SIL Open Font License 1.1（public/fonts/BarlowCondensed-OFL.txt）。
・自己配信（外部フォントCDNなし）。scripts/fonts/subset_fonts.py で公式TTFからWOFF2を生成し、
  src/app/fonts.css を出力。日本語は Google Fonts と同じ頻度順の unicode-range 121区分
  （scripts/fonts/zen-kaku-gothic-new-slices.txt）に分け、ページで使う文字の区分だけを読む。
  font-display: swap。全ウェイトを一括で読まない（実測: フィード1画面で40ファイル・約405KB。
  旧来の「1ウェイト丸ごと」なら約2.3MB/ウェイト）。
・システムフォント（system-ui / Hiragino / Yu Gothic UI / Meiryo / sans-serif）は読込失敗時・未収録文字の
  フォールバックとして残した（OSのフォントは削除していない）。
・撤去: BIZ UDPGothic・Outfit の WOFF2/OFL と @font-face、preload、offline.html と sw.js の参照、
  .font-latin / .t-overline / .t-stat。Inter・Roboto・Arial・Helvetica・Poppins・Montserrat・Open Sans・Lato・
  Noto Sans JP の指定はコードに存在しない（grep 確認）。
・注意: Zen Kaku Gothic New には palt（プロポーショナル詰め）機能が無い（GPOSは kern/mark/mkmk のみ）。
  そのためカナは全角の送りで組まれる。字間は 0 に統一し、広げていない。表示名（プロフィール見出し）だけ
  -0.02em 詰め・700、ロゴの「DayNet」は Barlow Condensed 600・+0.035em。

5. ブランド表示について
────────────────────────────────────────
・ブランド名 DayNet は維持。ヘッダーは「二つの三角形のマーク（幾何は design/DayNet の正本のまま）＋
  Barlow Condensed で組んだ DayNet」のロックアップに変更し、マークの色をUIトークン（ink＋accent）に合わせた。
・favicon / PWAアイコン / apple-touch-icon / OG画像（public/brand/*）は旧配色のまま差し替えていない。
  ブランド資産の改訂になるため、運営の判断が必要（HANDOFF に記載）。

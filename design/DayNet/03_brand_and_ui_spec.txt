DayNet / ブランド・UI仕様 v4
2026-10-07
今回の変更：名称、文字由来のマーク、配色、欧文・和文書体、ホーム、プロフィール、下部ナビ、ブランドボードを更新。
SNS機能、必須プロフィール、CinemiXの控えめな系列表示、既存データ保全は前版の要件を継承。

1. ブランド
正式表記：DayNet（DとNを大文字）。読み：デイネット。
説明：写真・動画・日記を投稿し、趣味の集まりで話せるSNS。
短いメッセージ：写真と動画で、日常をつなぐ。
マーク：角度と位置をずらした2つの三角形の輪郭。重なった領域を共有の場に見立てる。
DやNなどの字形から造形しない。カメラ、再生ボタン、頭文字モノグラムにも置き換えない。
CinemiXの文言：DayNetとCinemiXは、同じ系列のアプリです。
About、設定、プロフィール末尾へ小さく表示。URL未設定ならリンク化しない。
系列という説明は、データ連携・アカウント統合を意味しない。投稿に広告バナーを差し込まない。

2. HEXカラー
canvas #F7F4F5：薄いグレー寄りの背景。surface #FFFFFF：入力やモーダル。
ink #302B38：濃いプラムの文字、下ナビ、主要ボタン。
accent #EF7C68：コーラル。投稿入口、マークの前面三角形、重要な選択。
lilac #E2DDF0：淡いライラック。プロフィールの背景、投稿入口、アイコンの地。
muted #665F6E：補助文。line #D7D0DB：区切り。controlBorder #897F91：入力・補助ボタン枠。
focus #79528C：フォーカス線。success #2F674D、warning #82530A、error #AA3446。
補助面：#EDE8EF（タブの地）、#ECE7F3（返信の抜粋）、#F8D5CC（自分のDM）。
accent上の文字はink。白文字はink上で使用。色のみで成功・失敗・選択を伝えない。
前版の黄土色・ココア・紙色、青グラデーション、ガラス、ネオンは採用しない。

和文：BIZ UDPGothic 400/700。本文の判別しやすさを重視。
CSS例：font-family:'BIZ UDPGothic',sans-serif。欧文の小見出しは'Outfit','BIZ UDPGothic',sans-serif。

h2 20px/30px・700、セクション見出し16px/24px・700。

補助文12px/18px・400。見本内の短い時刻・補助タグ10〜11pxは非操作要素のみ。
ボタン13px/20px・700、入力16px/30px・400。下ナビラベル10px/15px、操作領域は56px高。

4. 寸法と構成
spacing scale 4,8,12,16,18,20,24,32,40,48,64px。
mobile320〜767、tablet768〜1119、desktop1120以上。
mobile左右18px、360未満は14px。feed最大640px。PC外枠最大1120px、左右32px。
PCは640pxのフィード＋264pxの補助索引、gap48px。左サイドバーは設けない。
1120px以上は上ナビへ移動。1120未満は底からmax(12px,safe-area)に浮いた72px高のナビ。
ナビ幅：min(100%-24px,610px)。角丸22px、背景ink、影0 6px 22px #302B381A。
ナビはホーム・集まり・投稿・DM・自分。投稿ボタンは44px四方・角丸13pxのコーラル面。
画面本文の末尾はcalc(112px + env(safe-area-inset-bottom))以上。入力中はキーボードに応じてナビを抑制し本文を隠さない。
ヘッダー72px。ロゴ幅165px（360未満150px）。検索・通知44px四方。
本文は通常のページスクロール。100dvh、safe-areaを使用。全体overflow:hiddenを避ける。
写真：上角12px・下角3px。原比率の閲覧導線を設け、保存原本を勝手に切らない。
標準写真見本は4:3。実フィードは4:5〜1.91:1を範囲として、全体表示へ拡大可能。
プロフィール：背景lilac、角丸18px、padding20px。必須3項目は縦並びのラベル＋値。
入力・ボタン角丸11px、タブ外枠10px、選択面7px。通常の投稿に外側のカード枠は付けない。
標準ボタン46px高、入力47px高、タッチ対象44×44px以上、アイコン23px。
タブも44px高以上。2行ラベルでも操作範囲を削らない。装飾だけの図形はタップ対象にしない。
罫線1px solid line。プロフィール内の線のみ#BEB3CA。入力枠はcontrolBorder。
影は下ナビ・モーダルのみ。モーダル0 16px 48px #302B3826。

5. 状態とアクセシビリティ
hover：明度を約5%下げる、150ms。active：translateY(1px)、押下領域を縮めない。
focus-visible：3px solid focus、offset3px。アウトラインを消さない。
selected：タブはink地＋白文字、下ナビはコーラル＋形/ラベル、反応はlilac＋aria-pressed。
下ナビ選択は色だけでなくaria-current=pageとラベルの700を併用。
disabled：opacity .45、操作不可理由を付記。read-onlyとdisabledを混同しない。
loading：レイアウトの高さを保つskeleton最大3件、aria-busy。アップロードには実進捗。
empty：「まだ投稿がありません。好きな集まりを探してみませんか。」＋集まりへ。
success：「投稿しました」＋投稿詳細。トーストrole=status、3秒。結果は画面にも残す。
warning：「接続が切れています。下書きはこの端末に保存しました。」＋再試行。
error：理由を入力直下に置き、本文と添付を保持。401再ログイン、404閲覧不可、429再開時刻を案内。
動画処理失敗は所有者だけに再選択/削除を案内。他者へ未完成媒体を公開しない。
動画は手動再生・playsInline。reduced-motionでは自動アニメーションを停止。
幾何学マークは非操作時alt=空、ロゴリンクならaria-label=DayNetのホーム。
HTMLのデモには実投稿のような成功表示を出さず、保存・送信されないことを操作時に知らせる。

6. 主要画面の仕様
A ホーム /feed
目的：知っている人・集まりの今日を読む。最重要は投稿媒体と投稿者、主操作は投稿と返信。
優先順：ロゴ・通知→小さい投稿入口→フィードタブ→今日の日付→投稿。大きなブランド見出しは置かない。
タブ：フォロー中＝フォロー相手＋自分の個人投稿。参加中＝参加コミュニティ投稿。みつける＝可視の公開投稿。
初期はフォロー中、publishedAt降順＋idで安定ソート。公開時にpublishedAtを確定し、編集では変更しない。既存公開投稿は移行時にcreatedAtを補填する。合成人気値は禁止。
mobileは浮いた下ナビ、写真の左右18px。PCは上ナビ＋右に参加集まりの短い索引だけ。
遷移：投稿→/post/id、投稿者→/u/username、集まり→/communities/slug。
取得失敗は再試行、オフラインは既表示分のみ（私的投稿を永続キャッシュしない）。

B 集まり /communities と /communities/[slug]
目的：趣味で交流を始める。重要情報は何の集まりか、参加条件、最近の投稿。
検索→参加中→見つける。幾何学シンボル・名前・説明・実人数を横長のリストにまとめ、薄い罫線で区切る。
mobileは一列、PCは最大960pxで説明幅を広げる。詳細は説明→参加状態→投稿タブ。
非公開は参加申請、管理者承認後だけ本文・メディア可視。申請却下・退出を扱う。
空なら「最初のひとことを書いてみませんか」。通信失敗は参加状態を楽観的確定しない。

C 投稿 /create
目的：写真・動画・文章を短い手順で投稿。最重要は添付プレビューと送信状態。
上に戻る／投稿する、本文、写真・動画を選ぶ／撮影、添付順、投稿先と公開範囲。
画像5枚まで、動画1本60秒まで、混在は今版なし。文章だけの日記も可。
mobile写真並べ替えは左右移動ボタン、ドラッグだけにしない。PCはドラッグ併用。
添付ごとに進捗・削除・代替テキスト入力。動画は処理完了まで下書き。
公開先変更時は非公開から公開への拡張を明示。戻る時は下書き保存か破棄を選ぶ。
投稿成功は詳細へ。失敗時はその場に入力と再試行を残す。

D プロフィール /profile, /u/[username]
目的：人柄から会話へ。上部の必須3項目は投稿一覧より前に表示。
順：ライラック面の中にアバター・表示名→自己紹介→イキリポイント→残念な弱点→趣味3つ。面の外に数と操作→投稿/日記/集まり。
自分は編集・共有。他者はフォロー・DMリクエスト。非公開は承認前に投稿本文を出さない。
mobile3項目はライラックのプロフィール面の中に、ラベルと値を上下に配置。行頭に三角・円・ひし形の識別記号。PCも順序は同じ。
プロフィールの集まり欄は本人が公開選択した公開コミュニティのみ。非公開参加先は出さない。
自分の保存・足あと・設定は補助メニューへ。投稿に架空の足あと数は置かない。
取得不能・ブロック時は存在の詳細を漏らさず戻る導線を出す。

E DM /messages, /messages/[id]
目的：会話を続ける。重要情報は相手、未読状態、送受信成否。
一覧と会話本文は別ページ。mobileは1画面1会話、PC最大720pxで本文を広げる。
相互フォローは通常会話、その他は受信リクエスト。未承認はテキスト1通まで、追送・リンクプレビューなし。
ブロック・通報はヘッダーのメニュー。入力最大2000書記素。添付DMは今版対象外。
送信中→送信済み／失敗、clientMessageIdで二重送信を防ぐ。
閲覧中5秒ポーリング、バックグラウンド停止。失敗時は再試行。E2E暗号化と称さない。

F オンボーディング /onboarding
目的：3項目を必ず選び、会話のきっかけを作る。1ページ3段階、進捗1/3など。
イキリポイント1個・残念な弱点1個・趣味3個。入力補助を付け、現版は運営管理の選択肢のみ。
最後にプレビューして確定。途中保存可、必須のスキップ不可。完了後も編集できるが条件は維持。
既存ユーザーは閲覧可能、新規投稿・コメント・DM開始の前に不足項目を補完させる。
サーバーで必須検証。選択肢を削除する際は既選択ユーザーを壊さず非推奨化する。

G 投稿詳細 /post/[id]
目的：投稿と返信の文脈を読む。媒体→本文→反応→コメント。返信は1階層まで。
編集は投稿者本人、削除は確認と実API。通報・ミュート・共有が機能する。
公開投稿のみ匿名共有ページあり。限定投稿OGPは汎用画像・ブランド名のみ。

H 通知／設定／About／管理
通知は未読と既読、既読更新は本人のみ。いいね・気持ちわかる・返信・承認を通知。
設定で非公開、DM、ブロック、足あと同意、ログアウト、退会、データ取得。
AboutにCinemiX系列説明。管理はロール検証済みの通報キュー、非表示・停止・理由・監査記録。
エラー時に管理者向け情報を一般利用者へ返さない。


7. ロゴと素材の指定
正本はassets/logo_horizontal.svg / logo_mark.svg。英字DayNetと幾何学マークを別の要素として扱う。
wordmark.svgは文字のみ、logo_horizontal_reverse.svgは濃色背景用、logo_mark_mono.svgは単色。
マークの正規viewBox=0 0 108 100。三角形A=(18,20),(79,38),(35,88)。B=(58,10),(90,75),(20,62)。
stroke8、fill none、round join。Aをink、BをaccentとしてBが前。角度・位置を勝手に正三角形へ揃えない。
片方を反転して六芒星にしたり、横向きの再生三角形に置き換えない。頭文字D/Nを隠し込まない。
最小表示：マーク24px、横ロゴ幅132px。16px用faviconは別の簡略化SVGを使用。
余白：マーク幅の0.18倍、横ロゴは高さの0.25倍。
192/512アプリアイコンは背景lilac込み。マークを中央80%の安全域に収める。
assets/apple_touch_icon_180.pngはiPhoneホーム画面用。不透明PNG。
SVGのパスを実装に使い、画像生成で別の文字や三角形へ描き直さない。
assets/icons/*.svgは24viewBox、stroke1.7、currentColor。
assets/avatar_*.svgは人物画像を使わないデモ用の幾何学アバター。実ユーザーは自分の画像を設定可能。
assets/ui_*.pngは390×844 CSS px、2倍解像度のモバイル見本。PCの正本は本書の寸法仕様。
assets/demo_walk.pngはAI生成の架空写真。初期の本番投稿に架空利用者として投入しない。
preview/index.htmlは見た目・遷移確認用。認証、送信、保存、検索、アップロードは実装対象でありデモでは動作しない。
8. 今回の移行範囲
DotNetのd字マーク、黄土色、Archivo、Zen Kaku Gothic New、DM Monoを現行デザインの正本から外す。
既存ソースに残る旧名称・manifest・通知・OGP・メール表示もDayNetへ。
内部のDB識別子・Cloudinaryの既存フォルダ・認証Providerの登録は名称変更だけで作り直さない。
